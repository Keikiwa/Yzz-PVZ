# Plants vs. Zombies (PVZ) - Gemini 4 Argon 复刻版本

本项目是一个基于 **Python 3** 和 **Pygame** 开发的《植物大战僵尸》机制复刻与探索版本。  
由开发者与 **Gemini 4 Argon** 协同构建，主要用于学习经典 2D 塔防游戏的状态机架构、动画序列帧渲染、网格碰撞检测与数值机制。

---

## 项目概况

- **项目名称**：PVZ - Gemini 4 Argon 复刻版本
- **核心语言**：Python 3.10+
- **图形与引擎**：Pygame
- **定位**：学习探索型复刻 Demo，还原经典操作手感与核心游戏循环。

---

## 当前已实现的机制

### 1. 关卡与环境
- **关卡设计**：内置 11 个阶梯式关卡，涵盖白天草地、夜晚草地以及带双水路的泳池关卡（第 11 关）；
- **场地适配**：支持水陆双重网格逻辑，水生植物（睡莲、猫尾草）与陆生植物依托睡莲进行水面种植；
- **自选与跳关**：右上角配备关卡切换传送门与快捷功能，方便快速调试与体验不同关卡。

### 2. 植物阵容（34 种）
- **阳光与生产**：向日葵、阳光菇、双子向日葵；
- **直射与射手**：豌豆射手、寒冰射手、双发射手、三线射手、机枪射手（四管迷彩钢盔）；
- **防御与阻拦**：坚果墙（含多级战损）、高坚果（含轻裂/重裂裂痕形态）、大蒜；
- **爆破与范围**：樱桃炸弹、火爆辣椒、土豆雷、窝瓜、寒冰菇、毁灭菇（核爆与弹坑）；
- **抛投类**：卷心菜投手、玉米投手（附带黄油定身）、西瓜投手、冰西瓜投手；
- **蘑菇与水生**：小喷菇、大喷菇（穿透紫烟）、魅惑菇（僵尸反戈）、睡莲、猫尾草（全图追踪刺）；
- **重型与扩展**：玉米加农炮（占两格手动瞄准落点）、地刺、杨桃、激光豆、魔术菇、龙舌兰。

### 3. 僵尸阵营与技能
- 普通僵尸、旗帜僵尸、路障僵尸、铁桶僵尸；
- 撑杆跳僵尸（起跳越过首株植物）；
- 读报僵尸（报纸撕碎后狂暴加速）；
- 铁栅门僵尸、橄榄球僵尸、小丑僵尸（偶发自爆盒）；
- 舞王僵尸与伴舞僵尸群；
- 水路专属：鸭子救生圈僵尸、潜水僵尸（潜水免伤，浮出啃食）。

### 4. 视听与体验
- 卡牌右下角配备阳光徽章与清晰费用数值；
- 原版背景音乐（Day、Night、Pool、Menu、Seeds 等音轨）与音效联动；
- 支持全屏/窗口模式自适应、键盘数字快捷选卡。

## 快速开始

### 1. 安装依赖
确保已安装 Python 3.10 或以上版本，然后执行：
```bash
pip install -r requirements.txt
```
*(主要依赖为 `pygame` 及基础图像处理库 `pillow`)*

### 2. 启动游戏
- **Windows 用户**：直接双击运行根目录下的 `启动植物大战僵尸.bat`；
- **命令行用户**：
```bash
python pvz_ten_levels.py
```

---

## 操作说明

- **鼠标左键**：点击顶部卡牌选择植物，再次点击有效草地/睡莲完成种植；点击铲子可移除场上植物；
- **数字键 1~8**：快速选取对应的植物卡牌；
- **空格键 / P 键**：暂停与继续游戏；
- **右上角快捷面板**：
  - `1x / 2x`：切换游戏运行速度；
  - `关卡切换`：自由跳转体验 1~11 任意关卡；
  - `音效 / 音乐`：一键静音或开启游戏原声。
