# 05 · 目标分层与模块划分

> 本文给出**目标架构**：分层、目录、每个模块的职责与允许的依赖方向、关键接口签名。
> 设计原则（整洁架构）：
> 1. **依赖指向内层**。领域层不知道 pygame、不知道磁盘、不知道窗口。
> 2. **跨层只经过接口**（Protocol / DTO），不传整个对象去"让对方自己翻"。
> 3. **可替换**：渲染后端、存档格式、输入来源都应是可替换的适配器。

**依赖规则（可用 import-linter 强制）**

| 层 | 允许 import |
|---|---|
| L1 domain | 仅标准库 + `domain/*` 自身 |
| L2 usecases | `domain/*`，不得 import `pygame` / `infra` / `app` |
| L3 app | `domain/*`、`usecases/*`、各 `ports` 的**接口**；实现通过构造注入 |
| L4 infra | `domain/ports`（实现它们）+ `pygame` + 标准库 |
| L0 main | 任何层（唯一组装点） |

违反即 CI 失败。这条规则是"防止架构腐化"的唯一硬保障。

## 3. 每个模块的职责边界（含"不该做什么"）

### 3.1 `domain/spec/*` —— 数据，无行为

```python
# domain/spec/plants.py
@dataclass(frozen=True)
class PlantSpec:
    id: str; name: str; cost: int; cooldown: float; max_hp: float
    behavior: BehaviorSpec            # 见 06 §3，替代 if/elif 链
    placement: PlacementRule          # land_only | water_only | carrier | upgrade_from:str|None
    tip: str

PLANTS: dict[str, PlantSpec] = {...}
```
- ✅ 唯一数值来源；🈲 不 import pygame、不含逻辑分支、不读文件。

```python
# domain/spec/field_layout.py
@dataclass(frozen=True)
class FieldLayout:
    cols: int; rows: int; is_pool: bool; pool_rows: frozenset[int]
    def center(self, col,row) -> tuple[int,int]
    def ground_y(self, row) -> int
    def cell_rect(self, col,row) -> RectTuple
    def is_water(self, row) -> bool
    def is_playable(self, x,y) -> bool
    def cell_at(self, x,y) -> tuple[int,int] | None
```
> **一次合并三张泳池常量表 + `_cell_at` 的硬编码区间**。`RectTuple` 用 `(x,y,w,h)` 元组，避免领域层 import pygame。

### 3.2 `domain/model/*` —— 实体只有状态与不变式

```python
class Zombie:
    def take_damage(self, amount: float, *, freeze: bool=False) -> DamageOutcome
    def apply_status(self, status: Status, duration: float) -> None
    def kill(self, cause: DeathCause) -> None
    @property alive(self) -> bool

class Plant:
    def take_damage(self, amount: float) -> DamageOutcome
    def kill(self, cause) -> None
```
- ✅ 保证不变式（`hp<=0 ⇒ alive=False`、`newspaper` 护盾先扣）；🈲 不引用 `World`/`Game`/`audio`；🈲 不 `lane_ground`（改为构造时注入 `center/ground_y`）。
- `Projectile` 只保留运动学状态与 `motion: MotionKind`；**不再有 `update(dt, game)`**。

### 3.3 `domain/rules/*` —— 规则是纯函数或依赖 ports 的服务

```python
# damage.py —— 唯一伤害权威
def apply_damage(world: World, zombie: Zombie, amount: float, *,
                 freeze: bool=False, source: DamageSource) -> None:
    outcome = zombie.take_damage(amount, freeze=freeze)
    world.events.emit(...)          # 受击闪白/报纸碎裂/减速
    if outcome.died: world.events.emit(ZombieDied(...))
```

```python
# planting.py —— 唯一放置规则（供点击与幽灵预览共用）
@dataclass(frozen=True)
class PlacementResult:
    ok: bool; reason: str; consumes: Plant | None   # 消耗的睡莲/被替换的植物

def evaluate_placement(world, layout, plant_id, col, row) -> PlacementResult
def commit_placement(world, layout, plant_id, col, row, *, sun: SunEconomy) -> bool
```
> 这一条消灭了 `_handle_click`(2211–2240) 与 `_draw_entities`(3886–3905) 的规则分叉。

```python
# combat.py
def step_plants(world, dt, events)      # 遍历植物，按 spec.behavior 调行为策略
def step_zombies(world, dt, events, lanes)  # 僵尸 AI
def step_projectiles(world, dt, events, targets)  # 运动 + 命中
```
> 这三个函数**不再出现在 `Game` 上**，也不再 `self.audio.play`。所有"表现欲"通过 `events.emit`。

```python
# wave_builder.py
def build_waves(level: LevelSpec, layout: FieldLayout, rng: Random) -> list[Wave]
```
> 纯函数：`(level, layout, rng) → waves`，**可离线单测**（传入固定 rng 断言成员构成）。

### 3.4 `domain/ports/*` —— 接口，全部是 Protocol

```python
class TargetProvider(Protocol):
    def best_target(self, *, prefer: str|None=None, exclude_hypnotized: bool=True) -> Zombie|None: ...
    def is_alive(self, zombie: Zombie) -> bool: ...

class LaneQuery(Protocol):
    def plants_in_row(self, row:int) -> Sequence[Plant]: ...
    def zombies_in_row(self, row:int) -> Sequence[Zombie]: ...

class EventSink(Protocol):
    def emit(self, event: GameEvent) -> None: ...

class SoundPort(Protocol):
    def play(self, sound: SoundId, cooldown: float = 0.0) -> None: ...
    def music(self, track: MusicTrack) -> None: ...

class SavePort(Protocol):
    def load(self) -> Progress: ...
    def save(self, progress: Progress) -> None: ...
```

### 3.5 `usecases/*` —— 用例只编排，不含规则

```python
# usecases/plant_seed.py
def execute(ctx: SessionContext, plant_id: str, col: int, row: int) -> PlacementResult:
    if ctx.session.overlay: return PlacementResult(False, "overlay")
    result = evaluate_placement(ctx.world, ctx.layout, plant_id, col, row)
    if not result.ok: return result
    if not evaluate_affordability(ctx.session, plant_id): return ...
    commit_placement(...)
    ctx.session.start_cooldown(plant_id)
    ctx.events.emit(SeedPlanted(...))
    return result
```
- ✅ 只依赖领域 + ports；🈲 不出现 `pygame.Rect`、不出现 `self.`。

### 3.6 `app/hud_layout.py` —— 纯函数布局（解决 C2）

```python
@dataclass(frozen=True)
class LayoutSpec:
    hit_regions: dict[HitId, RectTuple]        # 输入层唯一读取源
    draw_cmds: list[DrawCmd]                  # 渲染层唯一读取源
    mouse_canvas: tuple[int,int]              # 已转换到画布坐标

def build_battle_hud(view: BattleView, mouse_raw: tuple[int,int], viewport: Viewport) -> LayoutSpec
```
- ✅ 只依赖"视图快照"（`BattleView`：sun 值、卡槽列表、冷却比例、关卡名…），不依赖 `Game`、不依赖 `Surface`；
- ✅ **离线可测**：给定快照与鼠标坐标，断言 `hit_regions["SEED_sunflower"]` 是期望矩形；
- ✅ `mouse_canvas` 在布局内统一转换，杜绝 E6 的坐标混用。

`Input` 只读 `hit_regions`；`Renderer` 只吃 `draw_cmds`。**两者不再共享可变字段。**

### 3.7 `infra/*` —— 全部是适配器

- `pygame_viewport.py`：`Viewport` 类，持有 `canvas/real_screen/scale/offset`，提供 `to_canvas(raw)`、`present()`、`toggle_fullscreen()`。**全项目唯一调用 `pygame.mouse.get_pos()` 的地方在这里**（其余通过 `Viewport` 注入）。
- `pygame_renderer.py`：实现 `RenderPort.render_snapshot(snapshot)`；内部按 `renderers/*` 分派。现 `pvz_graphics.py` 的加载/序列帧能力迁入 `infra/sprites.py`，**签名改为吃快照**。
- `pygame_audio.py`：`AudioBank` 实现 `SoundPort`；`play(SoundId)` 用枚举而非裸字符串。
- `json_save.py`：`SavePort` 实现；**唯一读写 `pvz_save.json` 的地方**，带内存缓存与 `flush()`。
- `platform/windows_tweaks.py`：`timeBeginPeriod(1)` 包在 `if sys.platform == "win32"`。

## 5. 依赖图（目标）

```
main.py ──组装──> infra.*  ──实现──> domain.ports
   │                 │
   │                 └─> pygame
   └─> app.game_loop ─> app.controller ─> usecases.* ─> domain.rules ─> domain.model
                    └─> app.hud_layout                │                    │
                    └─> renderers/* ─> domain.ports.render  │            └─> domain.spec
                                                             └─> domain.ports.{save,sound,event}
```
- 内层零外部依赖（`domain/` 目录里出现 `import pygame` 即可判失败）；
- 具体实现只在 `main.py` 一处被 `new`；
- `infra/renderer` 与 `app/hud_layout` **互不认识**，都只认识 DTO。
